# Recorded session workflow

Google Drive is not connected to the member library. Putting a video in Drive does not create a lesson, a recorded session, or a Mux asset.

## Actual process

1. The source video lives in Drive or with the client.
2. The video is uploaded to Mux and finishes processing until it is ready for playback.
3. An admin opens Admin → Recorded Sessions.
4. The admin creates or edits the session, links the existing Mux asset, and sets the title, description, and order.
5. The admin publishes the session.
6. A member with access, or a Super Admin using demo access, opens it from the member library.

Unpublish removes it from the member library. It does not delete the Mux asset.

## What is not automated

There is no Drive-to-Mux sync and no Drive-to-library sync. A new Drive file still has to be supplied, uploaded to Mux, linked, and published.
